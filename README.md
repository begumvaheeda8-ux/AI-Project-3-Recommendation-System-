# AI Project 3 – AI Recommendation System

## Project Overview
This project is part of the DecodeLabs Artificial Intelligence Industrial Training Program, Batch 2026.

The objective is to build a simple recommendation system that suggests movies based on user preferences.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Conditional Logic
- Similarity Matching

## Key Features
- Takes user preferences as input.
- Matches preferences with movie data.
- Calculates similarity based on genre and movie type.
- Displays recommended movies.

## How to Run
1. Download the Jupyter Notebook.
2. Open it in Jupyter Notebook.
3. Run all code cells in order.
4. Enter your preferred genre and movie type.
5. Review the recommended movies.

## Project Objective
To understand recommendation logic, preference matching, and basic AI concepts.
